# Carbon MCP server, passkeys, and Console mode

> Connect AI clients to Carbon over MCP, sign in without a password, run the shop floor in Console mode, and use Carbon in Hindi, French, Polish, Portuguese, and Russian.

The Carbon MCP server lets Claude, Cursor, and other AI clients work with your data through Carbon's tools. Passkeys arrive for passwordless sign-in — register one from your account, sign in with Face ID, Touch ID, or a security key, and rename or remove passkeys you no longer use. Console mode runs a shared shop-floor device without a personal session.

## Languages

Carbon is now available in Hindi, French, Polish, Portuguese, and Russian, and the login page is translated too.

- Method types are now named for what they do: Pull from Inventory, Purchase to Order, and Make to Order (previously Pick, Buy, Make).
- CSV import tools.
- A Recalculate unit cost button on the item master.
- Purchased lead time is updated from a weighted yearly average.
- API key expiration dates are validated more strictly.
- Active time cards count toward duration calculations.
- Risk updates carry more detail.

- Markup is calculated correctly on purchased quoted parts.
- External notes show on the digital quote.
- Purchasing RFQ property updates save correctly.
- Audit logs that went missing are recorded again.
- Line-item document errors are handled instead of failing the page.
- Onshape sync tolerates a missing item.
- Faster dialogs and forms.
- A cross-site scripting vulnerability was closed.
