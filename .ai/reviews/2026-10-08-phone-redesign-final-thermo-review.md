# Final thermo-nuclear review: the whole feat/mobile-redesign branch

## TL;DR

- **Verdict:** not ready to merge. 80 findings, 23 of them MAJOR.
- **Rebase first (O1):** main is 59 commits ahead and has already rewritten 5 document headers that this branch also rewrites.
- **Desktop changes:** S1 (Escape), S9 (dialog clicks), M6 (MES operation screen), O7 (badge order) and R5/R6 (header order, wrapper div) break "desktop must not change".
- **Fixed after the review:** P1, the quote line Subtotal that included tax and the missing Tax row.
- **MES flashes the desktop layout (S2, M1):** MES never mounts `ViewportProvider`, so phones get the desktop layout first and swap after hydration.
- **Mounted twice (M2, M5):** MES bottom bars and the operation context row render twice and hide one copy with CSS.
- **Copy-paste (R1, R4, P2, O3):** the same step code in 4 report trees, 5 near-identical item headers, and 6 line summaries built two ways.
- **Hand-built twice (R2, S3):** app-bar actions are built by hand 7 times, and the account and create menus are rebuilt for the tab bar.
- **Scattered phone patches (S5, O4):** 76 one-off `max-md:opacity-100` classes, and `isPhone` checked 10 times in one file.
- **File size:** no file goes from under 1000 lines to over 1000 because of this branch.

Scope: `git diff origin/main...HEAD` (merge base `3070451ffb`): 9 commits, 720 files, +33k / −13k. Five reviewers worked in parallel, read-only. No typecheck, build or tests ran during the review. Every finding cites the file and line its reviewer read.
