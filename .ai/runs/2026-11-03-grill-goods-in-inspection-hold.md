# Grill: goods-in inspection hold

Spec in design. These resolutions go into the spec's Open Questions section
when the spec is written. Research: `.ai/research/2026-11-03-goods-in-inspection-hold.md`.

## Resolutions

- [x] Should the inspection states be new `receiptStatus` values or a separate field? — **Answer:** A separate field. `receipt.inspectionStatus` rolls up from the receipt's lots: `Not Required`, `Pending Inspection`, `Inspection In Progress`, `Inspection Passed`, `Inspection Failed`, `Partially Passed`, `Put Away`. The receipt stays `Posted`, so the GL, invoicing and void readers do not change (SAP, D365, NetSuite pattern).
- [x] How does Carbon hold untracked stock? — **Answer:** A quantity hold. An open lot (`Pending` or `In Progress`) holds its lot quantity at the storage unit its receipt line posted to. An outbound move that takes that (item, storage unit) below the held quantity is refused. Other stock in the same unit stays free. Passed quantity is free once the lot is terminal. Serial and batch stock keeps `On Hold`. The hold works with or without an inspection storage unit set.
- [x] Can the receiver change an inspected line's storage unit before posting? — **Answer:** Yes, but only to another non-nettable unit at the same location. Post refuses an inspected line on a nettable unit with a clear error that names the part. (Scope when the location has no inspection storage unit: see the next question.)
- [x] Must the inspection storage unit chosen in settings be non-nettable? — **Answer:** Yes. The settings action refuses a nettable unit.
- [x] What happens when an inspected line posts at a location with no inspection storage unit? — **Answer:** The post is refused. The error names the location and points to the setting. Reason (user): otherwise held stock counts as supply in a normal unit. Consequence: the demo datasets must seed an inspection storage unit at every location that receives inspected parts, and existing companies must set one before their next inspected receipt.
- [x] Who creates the putaway? What does it do? — **Answer:** A "Put Away" button on the receipt. It creates one Draft stock transfer linked to the receipt. The transfer has one line for each passed quantity not yet on a linked transfer: from the inspection storage unit to the part's nettable default storage unit (blank when there is none). Tracked parts get only `Available` units. `Rejected` and `On Hold` units never go on it. Stores complete it with the existing stock transfer flow. The receipt reaches `Put Away` when linked, completed transfer lines cover all passed quantity. Rejected stock stays in the inspection storage unit, outside on-hand, until the NCR disposition moves it.
- [x] What does Partial do for an untracked lot? — **Answer:** The Partial dialog asks for the accepted quantity. The accepted quantity becomes free and goes on Put Away. The rest stays held at the inspection storage unit until the lot's NCR closes, which already handles untracked quantities (Odoo, Business Central pattern). So the held quantity is: the lot quantity of an open lot, plus the rejected remainder of a Partial lot whose NCR is still open.
- [x] What ships in v1? — **Answer:** All four groups: (1) close the `On Hold` gaps in stock transfer, adjustment bin move, inventory count and server-side picking, and fix unpick resetting units to `Available`; (2) a `Cancelled` lot status, set when a receipt is voided; (3) stores queue views on the receipts list; (4) sales-return handling and a per-location rejected storage unit.
- [x] How do sales-return and inbound-transfer receipts take part? — **Answer:** Sales-return lines default to the location's inspection storage unit, so returned goods land in QC. The RMA line disposition stays the release; no inspection lot is created (the RMA module already holds returned units `On Hold`). Inbound transfers are unchanged: they move stock the company already accepted.
- [x] When does stock move into the rejected storage unit? — **Answer:** At reject time. A Reject on a tracked lot, or the rejected remainder of a Partial, posts a `Transfer` from the inspection storage unit to the rejected storage unit in the same step. The hold follows the stock, and the NCR disposition releases it. A full untracked Reject keeps today's write-off, now booked from the inspection storage unit. With no rejected unit set, the stock stays in the inspection storage unit.
