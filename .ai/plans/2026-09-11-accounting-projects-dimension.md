## Task 1: enum value + backfill + seed + types

**Depends on:** none
**Files:**
- Create (migration A): `pnpm db:migrate:new accounting-project-dimension-enum` → `ALTER TYPE ... ADD VALUE`
- Create (migration B): `pnpm db:migrate:new backfill-project-dimension` → backfill INSERT
- Modify: `packages/database/supabase/functions/lib/seed.data.ts`
- Modify (generated by `pnpm db:migrate`): `packages/database/src/types.ts`, `packages/database/supabase/functions/lib/types.ts`, `packages/database/src/swagger-docs-schema.ts`
- Copy from (precedent): `20260807090400_scrap-unscrap-enums.sql` + `20260808114732_backfill-scrap-reason-dimension.sql`

**Steps:**
1. `pnpm db:migrate:new accounting-project-dimension-enum`. Put ONLY this in it (its own transaction — a new enum value cannot be consumed in the same transaction that adds it):
   ```sql
   -- Project as a journal dimension. valueId on journalLineDimension is polymorphic → project.id.
   ALTER TYPE "dimensionEntityType" ADD VALUE IF NOT EXISTS 'Project';
   ```
2. `pnpm db:migrate:new backfill-project-dimension` (confirm its timestamp sorts AFTER migration A). Put:
   ```sql
   -- Backfill the default "Project" entity-backed dimension for every existing company
   -- group. New-company seeding covers this via functions/lib/seed.data.ts; this covers
   -- pre-existing groups. Idempotent: partial unique index on (name, companyGroupId)
   -- WHERE active = true + ON CONFLICT DO NOTHING. 'Project' was added to the
   -- "dimensionEntityType" enum in a prior migration, so it is safe to reference here.
   INSERT INTO "dimension" ("name", "entityType", "companyGroupId", "createdBy")
   SELECT 'Project', 'Project'::"dimensionEntityType", cg."id", 'system'
   FROM "companyGroup" cg
   ON CONFLICT ("name", "companyGroupId") WHERE "active" = true DO NOTHING;
   ```
3. In `seed.data.ts`, add to the `dimensions` array (after Scrap Reason): `{ name: "Project", entityType: "Project" },`.
4. `pnpm db:migrate` (applies both + regenerates types). Do NOT rebuild/reset the DB. If it fails to apply, STOP and report.
5. Confirm `dimensionEntityType` in `packages/database/src/types.ts` now includes `'Project'` (both the union near the top and the array-form mirror).

**Verify:**
```bash

# Expected: both compatibility checks exit 0 without writing business data; database typecheck exits 0.
```
