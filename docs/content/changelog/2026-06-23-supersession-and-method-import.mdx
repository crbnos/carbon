Picking lists turn demand into a pick against real storage units, so the floor gets a list instead of a hunt.

## Picking lists

[Picking lists](/docs/reference/picking) turn demand into a pick against real storage units. Label [printing](/docs/reference/printing) ships alongside them.

## Item supersession

[Item supersession](/docs/reference/change-orders/supersession) records that a part is being phased out and which successor replaces it, so [planning](/docs/reference/planning) and job creation pick up the change.

## Methods from CSV

Bills of materials and bills of process can now be [imported from CSV](/docs/reference/import-export).

## Document template customizer

[Document templates](/docs/reference/documents) now have a customizer.

<Accordion title="Improvements">

- Duplicate a purchase order.
- Inbound inspection for non-serial tracked items.
- Sourcing type is an item-level property.
- The import flow explains the Default row, clarifies Tracking Type, adds an optional unit cost, and lets value mappings be cleared.
- The customer portal page was redesigned, with filtering.
- Safety stock on the item planning chart, with clearer axis labels.
- Field label tooltips, and tooltips for RFQ dates; the RFQ "Expiration Date" is now "Due Date".
- Delete a 3D model from the viewer; the storage units tree opens expanded.
- Copy the company id from company settings.
- Document headings and body text follow the document theme.
- Turkish translation.
- MCP and self-hosting documentation.

</Accordion>
