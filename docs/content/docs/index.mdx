Carbon is a manufacturing system with **ERP** for orders, purchasing, planning, and accounting, and
**MES** for shop-floor <Term id="job">jobs</Term>, <Term id="operation">operations</Term>, and tracking. Both applications use one data model.

These technical docs describe system behavior, fields, and operations. For an end-to-end introduction,
follow the [**Guide**](/guides/order) from sales order through shipment and traceability.
