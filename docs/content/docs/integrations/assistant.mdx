## Slack

Connect **Slack** through **OAuth** to add the **Carbon Assistant** to your workspace and receive <Term id="nonconformance">nonconformance</Term> notifications. No additional configuration fields are required.
The same install also gives [workflows](/docs/reference/workflows) their Slack steps — sending messages,
finding users, creating channels — as any workspace listed on the card's **"Accounts"** tab; see
[workflow apps](/docs/integrations/workflow-apps).

<Steps>
  <Step>
  ### Start the Slack install

  Start authorization to open the Slack installation window.
  </Step>
  <Step>
  ### Choose your workspace

  Select a workspace and approve the installation. Carbon stores the connection.
  </Step>
</Steps>

| Setting | What it controls |
| --- | --- |
| Connection | Established by the Slack OAuth install — no keys to paste. |

Step-by-step: [Connect Slack](/docs/integrations/setup/slack).

<Callout type="warn">
Slack is unavailable in controlled (ITAR) environments.
</Callout>
