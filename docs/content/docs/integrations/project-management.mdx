Carbon can link <Term id="nonconformance">nonconformance</Term> **action tasks** to Linear or Jira issues. Status, assignee, and notes synchronize in both directions.

## Linear

Authenticate with a **Linear API key** (it begins with `lin_api`).

<Steps>
  <Step>
  ### Create the webhook in Linear

  In Linear's API settings, create a new webhook and paste the URL shown in Carbon's setup instructions
  (`/api/webhook/linear/<your company id>`) so Linear changes reach Carbon.
  </Step>
  <Step>
  ### Copy the signing secret

  Linear shows a **signing secret** on the webhook's detail page. Paste it into **Webhook Signing Secret**.
  Carbon then accepts only Linear-signed webhook requests that are no more than one minute old.
  </Step>
  <Step>
  ### Paste your Linear API key

  Provide your Linear API key. Carbon checks the `lin_api` prefix.
  </Step>
  <Step>
  ### Action tasks sync

  Link nonconformance action tasks to Linear issues. Carbon synchronizes status, assignee, and notes in both directions.
  </Step>
</Steps>

| Setting | What it controls |
| --- | --- |
| API key | Your Linear API key — Carbon checks the `lin_api` prefix. |
| Webhook signing secret | Optional. When set, webhook requests without a valid Linear signature are rejected. |

<Callout type="warn">
Webhooks without a saved secret remain compatible with older configurations, but Carbon cannot authenticate their requests. Configure a secret for every webhook.
</Callout>

## Jira

Connect over **OAuth**. The only setting is an optional webhook secret.

<Steps>
  <Step>
  ### Authorize over OAuth

  Authorize Carbon in Jira.
  </Step>
  <Step>
  ### Create the webhook in Jira (optional)

  To send Jira changes to Carbon immediately, go to **System → WebHooks** in Jira and create a
  webhook with the URL shown in Carbon's setup instructions (`/api/webhook/jira/<your company id>`),
  subscribed to **Issue updated** and **Issue deleted**. Fill in the webhook's **Secret** field, and paste
  the same value into **Webhook Secret** in Carbon. With it saved, Carbon only accepts webhook requests
  Jira has signed.
  </Step>
  <Step>
  ### Link an action task

  Link a nonconformance action task to a Jira issue. Carbon synchronizes status, assignee, and notes in both directions.
  </Step>
</Steps>

| Setting | What it controls |
| --- | --- |
| Webhook secret | Optional. When set, webhook requests without a valid Jira signature are rejected. |

<Callout type="warn">
Jira appears only when `JIRA_CLIENT_ID` is configured server-side. See [Environment variables](/docs/platform/self-hosting/environment-variables).
</Callout>
