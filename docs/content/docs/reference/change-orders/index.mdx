---
title: Change notices
description: How Carbon drafts an engineering change against real methods, reviews it as a diff, and releases it so downstream planning supersedes the versions it replaces.
---

A **change notice** groups related part changes, stages each change in a hidden draft, and releases them together. Live methods remain unchanged until release.

Select affected items, then edit each item's <Term id="bom">method</Term>—its bill of materials and bill of process—inside the notice. Planning, jobs, and costing continue to use the live item until release. Change notices are under **Items → Change Notices** and require `parts` permission.

## The affected item is the unit of work

A change notice contains a header and **affected items**. The picker accepts Parts only. Each affected item has its own <Term id="change-order-change-type">change type</Term>, edits, and cutover configuration.

Adding an affected item copies its **Active** method into a **Draft** method associated with the change notice. The draft is excluded from version selectors, copy targets, MRP, jobs, and costing until release. Edit it with the standard **Bill of Material**, **Bill of Process**, and **Part Properties** editors.

<Callout type="note" title="The draft is a real method, not a staged copy.">
Carbon does not mirror your edits into shadow tables. An affected item's edits live on an actual make method
whose change-notice id is set, which is why the diff is exact and release is just an activation. The draft is
invisible everywhere else precisely because that id is set — clearing it at release is what makes the draft
live.
</Callout>

## Find one in the list

**Items → Change Notices** lists every change notice. Because the affected item is the unit of work, each row
**expands** to reveal the parts it changes — one line per affected item, with its change type badge and, for a
Revision or Replacement Part, the old item number arrowed to the new one (**P000123 → P000124**). A New Part
shows a single id — it's net-new, with no predecessor to arrow from. You see what a change notice touches
without opening it.

To find the change notices that touch a specific part, use the **Item** filter. Pick one or more items and the
list narrows to change notices that affect them. The **Items** column that backs the filter is hidden by
default; turn it on from the column toggle if you want it in view or in a CSV export.
