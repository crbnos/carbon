---
title: External sharing
description: How Carbon's private, login-free links work — a customer accepts a quote, a supplier prices a request or answers a SCAR, a buyer watches order status.
---

Carbon can give external participants a **private link** to one live document without requiring a login. The URL is the only credential; anyone who has it can access the shared record.

Four features use external links:

<Cards>
  <Card title="Digital quotes" href="/docs/reference/quotes#digital-quotes">A **"Sent"** quote the customer accepts or rejects.</Card>
  <Card title="Supplier quotes" href="/docs/reference/supplier-quotes">A request the supplier prices and submits, line by line.</Card>
  <Card title="Customer portal" href="/docs/reference/customer-portal">A standing, read-only view of a customer's orders and shop-floor progress.</Card>
  <Card title="SCARs" href="/docs/reference/issues">A supplier corrective action request the supplier responds to.</Card>
</Cards>

<Callout type="note" title="Links expire with the document">
Each link is only as live as the record behind it: an expired or answered quote turns its page read-only, and a closed issue locks its SCAR. There is no separate link-revocation step to remember.
</Callout>

The RFQ preview and training assignments are not external shares. RFQ previews require a purchasing login, and training assignments require an employee login.
