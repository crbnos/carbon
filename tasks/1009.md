# Task Brief: Issue #1009 — Bulk Employee Invite

## Objective
Build the bulk employee invite feature for the ERP employee accounts screen. Users can enter multiple employees at once and send all invitations in a single action.

## Context
- **Issue:** https://github.com/crbnos/carbon/issues/1009
- **Branch:** loop/1009 (new worktree)
- **Repo:** /home/openclaw/carbon

## Relevant Code
- **Existing single invite route:** `apps/erp/app/routes/x+/users+/employees.new.tsx`
  - action: validates with `createEmployeeValidator`, calls `createEmployeeAccount`, sends invite email, redirects to personJob
- **Employees table:** `apps/erp/app/modules/users/ui/Employees/EmployeesTable.tsx`
  - Has a `<New label="Account" to="new?..." />` button at line 381 — this is what we need to accompany with "Invite Multiple"
- **Validator:** `createEmployeeValidator` in `apps/erp/app/modules/users/users.models.ts`
  - Fields: email, firstName, lastName, employeeType, locationId (all required)
- **Server fn:** `createEmployeeAccount` in `apps/erp/app/modules/users/users.server.ts`
- **Exports:** `apps/erp/app/modules/users/ui/Employees/index.ts` — add new component exports here
- **Module index:** `apps/erp/app/modules/users/index.ts` (or similar) — add any new exports

## What to Build
1. **New route:** `apps/erp/app/routes/x+/users+/employees.bulk-invite.tsx`
   - loader: same permissions as employees.new (create: "users"), load `getInvitable` 
   - action: validate array of rows (bulkCreateEmployeeValidator), iterate calling `createEmployeeAccount` + sendEmail per entry, collect per-row results, return summary (not a redirect — show per-row feedback)
   - default export: renders `<BulkInviteEmployeesModal invitable={invitable} />`

2. **New validator:** `bulkCreateEmployeeValidator` in `users.models.ts`
   - Array of employee objects, each: email, firstName, lastName, employeeType, locationId
   - Cross-row duplicate email detection

3. **New UI component:** `BulkInviteEmployeesModal` in `apps/erp/app/modules/users/ui/Employees/`
   - Multi-row form; start with 2 rows
   - Each row: email, firstName, lastName, employeeType (select), location (select) 
   - "Add row" (+) button, "Remove row" (x) per row
   - "Invite All" submit button
   - Per-row feedback after submission (success / already-exists / error)

4. **Edit EmployeesTable:** Add "Invite Multiple" button alongside the existing `<New>` button
   - Clicking it navigates to `bulk-invite?${params.toString()}`

5. **path.ts:** Add `bulkInviteEmployees: \`\${x}/users/employees/bulk-invite\``

## Acceptance Criteria (binding)
- Bulk invite button accessible from employee accounts screen
- Multi-row form with all 5 fields per row
- Dynamic add/remove rows
- Single submit sends all invitations  
- Per-row validation blocks submission on invalid/missing data
- Duplicate email detection across rows
- Per-invitation success/failure feedback shown
- Existing single-invite flow preserved (no regression)
- TypeScript compiles clean, lint passes
