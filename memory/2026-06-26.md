## Lessons

- pnpm --filter changes cwd to the package dir. Always use absolute paths.
- supabase migration deadlocks are transient — retry with delay fixes them.
- Docker group membership requires gateway restart (process inherits old groups).
- The outer loop dispatches fire-and-forget (nohup) — can't detect dispatch failures. Next heartbeat reconciles.
